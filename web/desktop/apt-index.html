Open Mailbox pour Ubuntu

Installation (Ubuntu 24.04 ou plus récent), puis les mises à jour arrivent avec apt upgrade :

curl -fsSL https://louis73cr.github.io/openmailbox/openmailbox.gpg | sudo tee /usr/share/keyrings/openmailbox.gpg >/dev/null
echo "deb [signed-by=/usr/share/keyrings/openmailbox.gpg] https://louis73cr.github.io/openmailbox stable main" | sudo tee /etc/apt/sources.list.d/openmailbox.list
sudo apt update && sudo apt install openmailbox

Code source : github.com/Louis73cr/openmailbox
